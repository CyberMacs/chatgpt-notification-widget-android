# ChatGPT Notification Widget v0.1.0

Első, telepíthető Android kiadás.

## Tartalom

- Natív Android alkalmazás és átméretezhető kezdőképernyő-widget.
- Csak a hivatalos ChatGPT Android alkalmazás értesítéseinek helyi kezelése.
- Room alapú értesítési előzmények, olvasott állapot és adatvédelmi beállítások.
- Kezdőknek szóló telepítési útmutató az `INSTALL.md` fájlban.

## Telepítő

Töltsd le a `ChatGPT-Notification-Widget-v0.1.0.apk` fájlt. Az APK v2 Android aláírással ellenőrzött, debug aláírással készült.
